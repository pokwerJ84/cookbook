# Japan Protein Cookbook v9

GitHub Pages-ready PWA with Supabase sync and Storage.

## Main files
- `index.html` – app shell
- `css/app.css` – styles
- `js/app.js` – application logic and recipe data
- `service-worker.js` – offline cache and update flow
- `manifest.webmanifest` – install metadata
- `supabase_cookbook_setup.sql` – database and Storage policies

## Deploy
Upload the contents of this folder to the repository root and enable GitHub Pages from `main / (root)`.

## v9 changes
- combinable filters
- explicit per-recipe family nutrition estimates
- shopping list
- cooking history
- PWA update prompt
- split CSS and JS
- safer handling of custom text
- simplified mobile filter panel
